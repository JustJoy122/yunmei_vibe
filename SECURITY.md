# Security Policy

## Supported Versions

This project is currently under active development (pre-1.0.0 release). 
Security updates are only provided for the latest `0.x` release. Please upgrade to the latest version to receive security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest 0.x | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Please **DO NOT** report security vulnerabilities through public GitHub issues.

Instead, please use the **Private vulnerability reporting** feature on GitHub (found under the "Security" tab of this repository). 

We will acknowledge your report within 48 hours and provide an estimated timeline for fixing the issue. We will keep you updated on the progress.

# 安全政策（中文版）

## 支持的版本

本项目目前处于活跃开发阶段（尚未发布 1.0.0 正式版）。
我们仅对最新的 `0.x` 版本提供安全更新。请务必升级到最新版本以获得安全修复。

| 版本   | 是否支持          |
| ------ | ----------------- |
| 最新的 0.x 版本 | :white_check_mark: |
| < 0.1.0  | :x:                |

## 报告安全漏洞

请**不要**通过公开的 GitHub Issue 报告安全漏洞。

如果您发现了安全漏洞，请使用 GitHub 仓库“Security”（安全）选项卡下的 **“Private vulnerability reporting”（私密漏洞报告）** 功能向我们发送报告。

我们会在 48 小时内确认收到您的报告，并提供修复问题的预计时间。我们会持续向您通报修复进度。
